# Tiny Crumbs on itch.io

Everything you need to publish Tiny Crumbs as a browser game on itch.io.

## Before you start

- Make an account at https://itch.io/register.
- To get paid you'll need a PayPal account or bank details, and to fill in a tax form. Payout accounts usually need you to be 18 or older, or a parent or guardian to set them up.

## Steps

1. Go to **Dashboard → Create new project**.
2. Fill in the form with the values below.
3. Click **Save & view page**, check that the game plays, then set **Visibility** to **Public** and save again.

| Field | What to enter |
|---|---|
| Title | Tiny Crumbs |
| Project URL | `tiny-crumbs` |
| Short description or tagline | Bake cookies, hire helpers, rebirth for Golden Crumbs. |
| Classification | Games |
| Kind of project | HTML |
| Release status | Released |
| Pricing | **No payments** to start, or **Donate** with a suggested $2 (players can still play free) |
| Uploads | Upload `tiny-crumbs-html5.zip`, then tick **This file will be played in the browser** |
| Embed options → Viewport dimensions | 1280 × 720 |
| Embed options (ticks) | **Mobile friendly** (orientation: Default), **Fullscreen button**, **Automatically start on page load** |
| Details → Description | Paste the description below |
| Genre | Simulation |
| Tags | `clicker`, `idle`, `incremental`, `cookies`, `casual`, `singleplayer`, `relaxing`, `html5` |
| AI generation disclosure | Answer **Yes**: the code was written with an AI assistant |
| Cover image | `images/itch-cover-630x500.png` |
| Screenshots | The three `screenshot-*.png` files |

## Description (paste into Details → Description)

> **Tiny Crumbs** is a cozy clicker set on the lid of a butter-cookie tin.
>
> Tap the cookie to bake. Spend your cookies on helpers who bake for you: Tappers with wooden spoons, Nanas with rolling pins, Wheat Farms, Brick Ovens, Bakeries, Factories, Shipping Ports and a Cookie Lab.
>
> **Features**
> - 8 helpers, each stronger than the last one you bought
> - Stronger Hands: level up your clicks, with bonus jumps at levels 25, 55 and 85
> - Dozens of upgrades that multiply your helpers and your clicks
> - Gilded biscuits: catch them for Oven Rush, Hot Hands or a Windfall of cookies
> - Rebirth for Golden Crumbs, a permanent bonus that carries into every new run
> - Refined Recipes: spend Golden Crumbs to make every upgrade stronger
> - Saves automatically, and your helpers keep baking while you're away (up to 8 hours)
>
> **Controls:** click or tap the cookie. Keyboard: Tab to the cookie and press Enter or Space.
>
> Plays in any modern browser on desktop or phone. No download needed.

## After it's live

- Post it on r/incremental_games (read their rules first; they have a weekly thread for new games).
- Add a **devlog** on itch.io each time you update the game. Followers get notified.
- To update the game later, upload a new zip in **Edit game → Uploads** and delete the old one.
